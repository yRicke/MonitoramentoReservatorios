# Manual do Usuario

## Acesso

1. Abrir `/entrar/`.
2. Informar nome e senha.
3. Acessar o dashboard principal.

## Dashboard

O dashboard oferece:

- busca por nome/status;
- cards por reservatorio;
- medias por periodo;
- filtros de tempo entre `15m` e `90d`.

## Tela de detalhe

No detalhe do reservatorio o operador encontra:

- status atual;
- metricas recentes;
- graficos historicos;
- acesso para editar;
- acesso para calibrar;
- acesso ao relatorio;
- acesso ao controle do alerta sonoro.

## Rotina diaria recomendada

1. verificar reservatorios sem dados recentes;
2. revisar cards em `atencao` ou `perigo`;
3. abrir detalhes com oscilacao ou fora de faixa;
4. acompanhar historico e tendencia;
5. iniciar calibracao quando houver deriva de sensor.
