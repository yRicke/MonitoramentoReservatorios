# Relatorios

## Visao geral

Cada reservatorio possui uma rota de relatorio em:

`/reservatorios/<id>/relatorio/`

## O que o relatorio mostra

- dados principais do reservatorio;
- metricas recentes;
- graficos historicos herdados do detalhe;
- medias por varios periodos;
- data e hora de geracao.

## Exportacao

O fluxo atual usa o proprio navegador:

- visualizacao para impressao;
- opcao de salvar como PDF;
- suporte a `?download=1` para abrir o relatorio com impressao automatica no browser.

## Uso sugerido

- registrar o estado de um reservatorio antes e depois de manutencao;
- guardar evidencias de calibracao e acompanhamento;
- anexar relatorios em atividades tecnicas ou academicas.
