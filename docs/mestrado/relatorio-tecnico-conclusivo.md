# Relatorio Tecnico Conclusivo

## Enquadramento

Para fins academicos, a documentacao deste repositorio deve separar claramente:

- o que esta implementado no codigo;
- o que e legado de arquitetura;
- o que e melhoria futura.

## Pontos centrais para o texto conclusivo

- o prototipo local esta funcional e integrado entre ESP32 e Django;
- o fluxo ativo foi simplificado para `ponto_unico`;
- calibracao, alerta sonoro e relatorio estao implementados;
- endurecimento para producao ainda e necessario.

## Cuidado metodologico

O conceito de comparar antes/depois da intervencao continua valido para o contexto do mestrado, mas o codigo atual nao implementa mais dois pontos operacionais distintos no payload novo.
