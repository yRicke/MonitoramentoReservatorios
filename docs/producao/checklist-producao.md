# Checklist de Producao

- Confirmar banco de dados produtivo e politica de restauracao.
- Desligar `DEBUG` e revisar `ALLOWED_HOSTS`.
- Criar `.env.example` sem segredos reais.
- Definir HTTPS e topologia de rede.
- Formalizar logs, auditoria e monitoramento.
- Revisar seguranca do painel AP do ESP32.
- Validar sensores com referencia externa.
- Definir protocolo oficial de calibracao.
- Confirmar hardware final, vedacao e diagrama eletrico.
- Confirmar estrategia de update do firmware.
- Padronizar backup automatico.
- Homologar versao de Python usada em campo.
