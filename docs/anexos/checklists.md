# Checklists

## Instalacao local

- Dependencias Python instaladas.
- Migracoes aplicadas.
- Usuario criado.
- Servidor Django acessivel na rede local.

## Configuracao do ESP32

- `reservatorio_id` correto.
- token do reservatorio copiado.
- `ip_django` correto.
- SSID e senha do AP definidos.
- painel salvo e ESP32 reiniciado.

## Operacao diaria

- dashboard sem reservatorios sem dado prolongado;
- alertas revisados;
- historico recente validado;
- sensores suspeitos encaminhados para calibracao.

## Calibracao

- sensor selecionado corretamente;
- sessao iniciada;
- estabilidade observada;
- referencia externa confirmada;
- calibracao salva e conferida no detalhe.
